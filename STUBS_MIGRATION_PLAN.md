# Generated Classes → PEP 561 Stubs Migration

Replace the ~5,500 runtime classes in `src/compas_ifc/entities/generated/{IFC2X3,IFC4,IFC4X3}/` with three `.pyi` stub files. Runtime collapses to one `Base` class plus 12 hand-written extensions, dispatched through schema introspection. IDE autocomplete and EXPRESS docstrings on raw IFC attributes are preserved through the stubs.

This document is the **canonical plan** for the work and is designed to span multiple sessions. When picking up a session: read the **Status** section, find the first unchecked phase, read its phase block, execute, then update the Status checklist before stopping.

Branch: continue on `finalizing` (no new branch).

## Locked decisions

1. **Inverse-attribute call style: preserve `()`.**
   `wall.ContainedInStructure()` keeps its parens. Rationale (user): the parens mark the syntactic distinction between direct attributes (`wall.Name`) and inverse attributes (`wall.ContainedInStructure()`), which is a useful signal even though ifcopenshell's native API uses parens-less inverses.
   Implementation: `Base.__getattr__` consults `schema.declaration_by_name(self.entity.is_a()).all_inverse_attributes()` (via cache) and returns a zero-arg lambda for inverse names; direct attribute names return the wrapped value directly.

2. **Stub granularity: one `.pyi` per schema, git-tracked.**
   Three files: `IFC2X3.pyi`, `IFC4.pyi`, `IFC4X3.pyi`. Static text, committed to the repo, regenerated by maintainers on schema bumps.

3. **Schema coverage: keep all three.**
   IFC2X3, IFC4, IFC4X3 stubs all generated and tracked.

4. **Branching: stay on `finalizing`.** No new branch. The cleanup is a continuation of the chapter-4 alignment work.

5. **Extension mechanism: `@extends` decorator + `self`-annotation.**
   Replace today's class-name shadowing (`class IfcElement(IfcElement):`) with explicit registration:
   ```python
   from compas_ifc.entities.base import Base, extends

   if TYPE_CHECKING:
       from compas_ifc.entities.generated.IFC4 import IfcElement


   @extends("IfcElement")
   class IfcElementExtras(Base):
       @property
       def parent(self: "IfcElement"):
           relations = self.ContainedInStructure()
           ...
   ```
   - Class names become descriptive (`IfcElementExtras`) — no shadowing.
   - `@extends("IfcClass")` is the registration; multiple classes per extension and multiple extensions per class are both supported.
   - `self: "IfcElement"` annotation gives IDE autocomplete inside method bodies without faking inheritance from a non-existent runtime class.
   - Optional schema scoping via `@extends("X", schemas={"IFC4", "IFC4X3"})` — defaults to all schemas when omitted.
   - Runtime parent is always `Base`; the synthetic `Extended<X>` class built by `Base.__new__` mixes in matched extensions ordered by IFC inheritance depth so `super()` chains resolve correctly.

## Phase 1 — Runtime: make `Base` self-sufficient

Make `Base` work without the generated subclasses present. After this phase, the generated tree on disk is unused at runtime but still exists; this lets us run the full test suite as a regression gate before deleting anything.

**File: `src/compas_ifc/entities/base.py`**

- [ ] **Add an extension registry and `extends` decorator** at module scope:
  ```python
  _extension_registry: dict[str, list[tuple[type, set[str] | None]]] = {}

  def extends(*ifc_classes: str, schemas: set[str] | None = None):
      """Register a Base subclass as an extension for one or more IFC classes.

      Applied to entities where `entity.is_a(<ifc_class>)` is True. If `schemas`
      is given, the extension is only applied for matching schemas.
      """
      def wrap(cls):
          for ifc_class in ifc_classes:
              _extension_registry.setdefault(ifc_class, []).append((cls, schemas))
          return cls
      return wrap
  ```

- [ ] **Add `Base.__getattr__`** that proxies to `self.entity`, wrapping nested entities back through `self.file.from_entity(...)`. Inverse-attribute names return a zero-arg lambda (preserves `wall.ContainedInStructure()` semantics).

  Sketch:
  ```python
  def __getattr__(self, name):
      if name.startswith("_") or name in {"entity", "file"}:
          raise AttributeError(name)
      entity = object.__getattribute__(self, "entity")
      if entity is None:
          raise AttributeError(name)
      if name in self._inverse_attribute_names():
          return lambda: self._get_inverse_attribute(name)
      try:
          return self._get_attribute(name)
      except (AttributeError, RuntimeError):
          raise AttributeError(name)

  @classmethod
  def _inverse_attribute_names_for(cls, schema, ifc_class):
      # cached per (schema, ifc_class)
      decl = schema.declaration_by_name(ifc_class)
      return {ia.name() for ia in decl.all_inverse_attributes()}

  def _inverse_attribute_names(self):
      key = (self.schema, self.entity.is_a())
      cache = Base._inverse_cache
      if key not in cache:
          cache[key] = self._inverse_attribute_names_for(self.file._schema, self.entity.is_a())
      return cache[key]
  ```
  Caching is essential — `__getattr__` is on the hot path.

- [ ] **Add `Base.__setattr__`** dispatching IFC writes to `_set_attribute`. Heuristic: `name[0].isupper()` AND `entity is not None` ⇒ IFC write; otherwise normal assignment.

  Sketch:
  ```python
  def __setattr__(self, name, value):
      if name and name[0].isupper():
          entity = self.__dict__.get("entity")
          if entity is not None:
              self._set_attribute(name, value)
              return
      super().__setattr__(name, value)
  ```

- [ ] **Rewrite `Base.__new__`** — drop the generated-class lookup. Read matched extensions from the registry, filter by schema, sort by IFC inheritance depth (deepest first so `super()` walks parents):
  ```python
  def __new__(cls, entity, file=None, extensions=None):
      if hasattr(entity, "wrappedValue") and not entity.is_a("IfcRoot"):
          # type definitions like IfcLengthMeasure
          return TypeDefinition(entity, file)

      schema_name = file._schema.name() if file is not None else "IFC4"
      matched = []
      for ifc_class, registered in _extension_registry.items():
          if entity.is_a(ifc_class):
              for ext_cls, ext_schemas in registered:
                  if ext_schemas is None or schema_name in ext_schemas:
                      matched.append((ifc_class, ext_cls))

      # Custom extensions passed via `extensions=` keep working
      if extensions:
          for ifc_class, ext_cls in extensions.items():
              if entity.is_a(ifc_class):
                  matched.append((ifc_class, ext_cls))

      if matched:
          # Sort deepest-first so super() walks the IFC inheritance chain.
          matched.sort(key=lambda pair: -_ifc_depth(file._schema, pair[0]))
          # De-duplicate while preserving order.
          seen = set()
          ordered = []
          for _, ext_cls in matched:
              if ext_cls not in seen:
                  seen.add(ext_cls)
                  ordered.append(ext_cls)
          extended = type(f"Extended{entity.is_a()}", tuple(ordered), {})
          return object.__new__(extended)
      return object.__new__(Base)
  ```

  Helper:
  ```python
  _depth_cache: dict[tuple[str, str], int] = {}

  def _ifc_depth(schema, ifc_class):
      key = (schema.name(), ifc_class)
      if key not in _depth_cache:
          decl = schema.declaration_by_name(ifc_class)
          depth = 0
          while decl.supertype():
              depth += 1
              decl = decl.supertype()
          _depth_cache[key] = depth
      return _depth_cache[key]
  ```

  **Caveat:** the current code distinguishes `Base` entities from `TypeDefinition` via `hasattr(entity, "wrappedValue")`. Verify this still picks the right path for the simple-type wrappers (e.g. `IfcLengthMeasure`).

- [ ] **Replace the two `isinstance` checks**:
  - In `print_spatial_hierarchy`: `isinstance(self, IfcObjectDefinition)` → `self.entity.is_a("IfcObjectDefinition")`.
  - In `print_properties`: `isinstance(self, IfcObject)` → `self.entity.is_a("IfcObject")`.
  - Drop both `importlib.import_module` calls.

- [ ] **Initialize the inverse-attribute cache** as a module-level dict: `_inverse_cache: dict[tuple[str, str], frozenset[str]] = {}`.

- [ ] **Add a derived-attribute cache and skip writes to derived attrs.**
  IFC EXPRESS marks some attributes as DERIVED (computed from other fields, not directly settable — e.g. `IfcSIUnit.Dimensions`). The old generator emitted no-op setters for these via `TEMPLATE_DERIVED`. Without that, `setattr(entity, "Dimensions", value)` raises `TypeError: Unable to set derived attribute` from ifcopenshell. `_set_attribute` must early-return when the attribute is derived. Cache lookup is the same shape as the inverse-attribute cache:
  ```python
  def _derived_attribute_names(self):
      ...  # cached frozenset, populated from
           # decl.derived() + decl.all_attributes()

  def _set_attribute(self, name, value):
      if name in self._derived_attribute_names():
          return
      ...
  ```

## Phase 2 — Extensions: refactor with `@extends` decorator

Rewrite the 12 extensions to use the registry-based mechanism from Phase 1. Each file follows this canonical pattern.

Before:
```python
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from compas_ifc.entities.generated.IFC4 import IfcElement
else:
    IfcElement = object


class IfcElement(IfcElement):
    @property
    def parent(self):
        relations = self.ContainedInStructure()
        if relations:
            return relations[0].RelatingStructure
        return super().parent
```

After:
```python
from __future__ import annotations
from typing import TYPE_CHECKING

from compas_ifc.entities.base import Base, extends

if TYPE_CHECKING:
    from compas_ifc.entities.generated.IFC4 import IfcElement


@extends("IfcElement")
class IfcElementExtras(Base):
    """Adds spatial-parent resolution to entities of class IfcElement."""

    @property
    def parent(self: "IfcElement"):
        relations = self.ContainedInStructure()
        if relations:
            return relations[0].RelatingStructure
        return super().parent
```

## Phase 3 — Stub generator

Repurpose `src/compas_ifc/entities/generator.py` to emit one `.pyi` per schema instead of ~3,000 `.py` files.

Output format example:
```pyi
# IFC4.pyi (excerpt)
from typing import Optional, Union

class IfcWallTypeEnum(str):
    items: tuple = (
        "MOVABLE", "PARAPET", "PARTITIONING", "PLUMBINGWALL",
        "SHEAR", "SOLIDWALL", "STANDARD", "POLYGONAL",
        "ELEMENTEDWALL", "USERDEFINED", "NOTDEFINED",
    )

class IfcRoot:
    GlobalId: str
    OwnerHistory: Optional["IfcOwnerHistory"]
    Name: Optional[str]
    Description: Optional[str]

class IfcObjectDefinition(IfcRoot):
    def HasAssignments(self) -> tuple["IfcRelAssigns", ...]: ...
    def IsDecomposedBy(self) -> tuple["IfcRelAggregates", ...]: ...
    ...

class IfcWall(IfcBuildingElement):
    """IfcWall — wall element. <EXPRESS docstring>"""
    PredefinedType: Optional["IfcWallTypeEnum"]
```

Rules:
- **Direct attributes** → class-level annotated assignments.
- **Inverse attributes** → zero-arg methods returning a tuple (matches Phase 1 dispatch — preserves `wall.ContainedInStructure()` style).
- **Enums** → declared as `class X(str): items: tuple = (...)`.
- **Extensions** → walk `Base._extension_registry` (populated by the `@extends` decorators when `entities.extensions` is imported). For each registered extension, append its typed properties/methods to the matching IFC class in the stub. Use `inspect.signature` to extract signatures, not source bodies. Schema scoping (`@extends(..., schemas=...)`) is honored — IFC2X3-only extensions only appear in `IFC2X3.pyi`.

Implementation steps:

- [ ] Adapt `EntityGenerator.TEMPLATE` to emit `.pyi` syntax (no method bodies for direct attributes — use class-level annotations).
- [ ] Adapt `InverseAttributeGenerator.TEMPLATE` to emit `def name(self) -> tuple["X", ...]: ...`.
- [ ] Adapt `EnumGenerator.TEMPLATE` to emit `class X(str): items: tuple = (...)`.
- [ ] Add a helper that, given a class name, walks the matching extension class (if any) and emits its property/method signatures into the same stub class block.
- [ ] Change `Generator.generate()` to write **one combined `.pyi`** per schema instead of one `.py` per declaration. Output paths:
  ```
  src/compas_ifc/entities/generated/IFC2X3.pyi
  src/compas_ifc/entities/generated/IFC4.pyi
  src/compas_ifc/entities/generated/IFC4X3.pyi
  ```
- [ ] Sort declarations topologically so parent classes precede children (required for `class IfcWall(IfcBuildingElement):` forward references — or use string forward refs throughout to sidestep order).
- [ ] Run the generator three times (one per schema) and commit the three `.pyi` files.

## Risks & mitigations

| Risk | Mitigation |
|---|---|
| `Base.__setattr__` heuristic (PascalCase = IFC write) misclassifies a future internal attribute | Convention: keep all internal `Base` state as `_`-prefixed or lowercase. Add a brief comment in `Base.__setattr__` documenting the convention. |
| `Base.__getattr__` adds per-call overhead | Cache inverse-attribute names per `(schema, ifc_class)` (already in plan). Direct attribute access reduces to one dict lookup + one `getattr(self.entity, …)` call — same as today's generated property indirection. Benchmark Duplex_A round-trip if uncertain. |
| Extension MRO subtle break when synthetic class differs | Phase 1+2 verification gate (full thesis suite + 6 scripts) covers realistic call patterns. If a regression appears, the failure is localized to a specific extension method. |
| External users importing `compas_ifc.entities.generated.IFC4.IfcWall` at runtime | Documented in CHANGELOG. Stubs make `if TYPE_CHECKING:` imports continue to work. Anyone relying on runtime `isinstance` checks gets a clear migration path (`is_a()`). |
| Sphinx cross-refs in docstrings to `compas_ifc.entities.generated.IFC4.X` may not resolve to `.pyi` | Two fallback options at Phase 7: (i) drop those refs and use `:class:\`ifcopenshell.entity_instance\`` instead; (ii) leave them — most builds tolerate unresolved refs as warnings. |
| `compas_viewer` plugin / `IfcBrepObject` registration depends on imports that go through `entities.generated` | Verified at start: `brep/__init__.py` only imports `Base` and the extensions module, not generated classes. No action needed. |
| The `TypeDefinition` fallback path in `Base.__new__` regresses for `IfcLengthMeasure` etc. | Phase 1 explicitly preserves `hasattr(entity, "wrappedValue")` check and routes to `TypeDefinition`. Spot-check by reading a unit-bearing IFC entity. |
