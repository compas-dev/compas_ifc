Examples

Worked examples accompanying the tutorials.

The scripts/ directory of the source repository is split into:

  • scripts/tutorials/ — short, focused examples that exercise the front-end API one feature at a time.

  • scripts/dev_tests/ — longer feature-regression scripts kept around for development. These are not pytest tests; the proper pytest suite lives in tests/, and the formal evaluation suite for chapter 4 of the underlying thesis lives in thesis/appendix/A/ with its own run_all.py runner.

Each script is intended to be runnable from the repository root with the compas-ifc conda environment.
