.. rst-class:: lead

The user-facing API of COMPAS IFC.

The front-end consists of two main classes —
:class:`~compas_ifc.bim.BuildingInformationModel` and
:class:`~compas_ifc.element.GenericElement` — plus the validation engine
and the parametric geometry representations. Internal modules are listed
for contributors.
